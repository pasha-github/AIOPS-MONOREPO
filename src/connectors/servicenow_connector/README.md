# ServiceNow Connector

Interact with the ServiceNow API for incidents, change requests, and knowledge base operations.

## Configuration

- `SERVICENOW_INSTANCE_URL`
- `SERVICENOW_USERNAME`
- `SERVICENOW_PASSWORD`
- `SERVICENOW_AUTH_TYPE`
- `prefix`

## Tools

- `list_incidents`
- `create_incident`
- `update_incident`
- `resolve_incident`
- `list_change_requests`
- `create_change_request`
- `update_change_request`
- `list_knowledge_bases`
- `list_kb_articles`
