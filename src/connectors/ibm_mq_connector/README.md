# IBM MQ Connector

Connector for IBM MQ administrative operations and support endpoints.

## Configuration

- `URL_BASE`
- `USER_NAME`
- `PASSWORD`
- `LOGS_URL`
- `SSH_HOSTNAME`
- `SSH_USERNAME`
- `SSH_PASSWORD`
- `VERIFY_TLS`
- `prefix`

## Tools

- `dspmq`
- `runmqsc`
- `get_mq_logs`
- `run_commands_ssh`
