# Customer App Connector

Start, stop, and check status of the customer app.

## Configuration

- `prefix`

## Tools

### `start_customer_app`

Starts the customer app using `POST /api/start`.

### `stop_customer_app`

Stops the customer app using `POST /api/stop`.

### `get_customer_app_status`

Checks the app status using `GET /api/status`.
